Implementasi Frontend Admin: Create Schedules dan Approval Top Up

1. Struktur routing
- Halaman admin tersedia di `frontend_h2h/src/router/index.ts`.
- Rute jadwal: `/admin/schedules` -> `ScheduleManagement.vue`.
- Rute approval topup: `/admin/topup-approval` -> `TopupApproval.vue`.

2. Komponen utama
- `SidebarProvider`, `SidebarInset`, `AppSidebar`, dan `SiteHeader` digunakan untuk tata letak admin.
- UI card, table, dialog, button, badge, input, dan label berasal dari kumpulan komponen UI lokal.
- `useToast` dipakai untuk notifikasi operasi sukses/gagal.

3. Create / manage schedules (`ScheduleManagement.vue`)
- Mengambil data via API:
  - `/schedules` untuk daftar jadwal.
  - `/routes` untuk data rute.
  - `/vehicles` untuk daftar kendaraan.
  - `/cities` untuk daftar kota.
- Fitur filter:
  - filter rute berdasarkan `route_id`.
  - filter tanggal perjalanan berdasarkan `travel_date`.
- Dialog tambah/edit jadwal:
  - Pilih rute existing, atau buat rute baru secara inline.
  - Pilih kendaraan, tanggal perjalanan, jam berangkat, jam tiba, dan harga tiket.
  - Validasi sederhana: semua field wajib, rute harus lengkap, kota asal dan tujuan tidak boleh sama.
- Submit jadwal:
  - `POST /schedules` untuk membuat jadwal baru.
  - `PUT /schedules/:id` untuk memperbarui jadwal.
  - Setelah sukses, memuat ulang daftar jadwal.
- Hapus jadwal:
  - Konfirmasi via dialog.
  - `DELETE /schedules/:id` untuk menghapus.
- Format tampilan:
  - `formatDate()` untuk tanggal format Indonesia.
  - `formatCurrency()` untuk harga dalam `Rp`.
  - `formatTime()` agar jam selalu 2-digit.

4. Approval Top Up (`TopupApproval.vue`)
- Mengambil daftar topup admin dengan `GET /topups`.
- Menampilkan tabel permintaan topup:
  - ID Top Up, mitra, nominal, status, tanggal, dan tombol aksi.
- Aksi untuk status `pending`:
  - Approve: `POST /topups/:id/approve`.
  - Reject: `POST /topups/:id/reject`.
- Detail Top Up:
  - Dialog menampilkan informasi lengkap, termasuk bukti transfer, metode pembayaran, catatan, dan status approval.
  - Jika topup sudah selesai, tampilkan informasi approver dan tanggal approve/reject.
- Notifikasi realtime untuk proses loading, sukses, dan error.

5. Keterangan tambahan
- Proyek frontend ini sebenarnya dibangun dengan Vue 3 + TypeScript dan Vite, bukan Next.js.
- `api` service digunakan sebagai wrapper HTTP untuk semua request backend.
- Halaman admin ini sudah mengimplementasikan pola UI yang sesuai dengan desain template modern: card, modal dialog, dan tabel responsif.

6. Rekomendasi untuk laporan
- Sebutkan bahwa implementasi admin meliputi:
  - pembuatan jadwal perjalanan dengan manajemen rute dan kendaraan,
  - validasi input,
  - penggunaan dialog untuk tambah/edit/hapus,
  - serta proses approval topup mitra dengan detail dan tombol approve/reject.
- Jelaskan bahwa frontend memudahkan admin mengelola data secara cepat melalui UI komponen yang konsisten.

7.2. Script ScheduleManagement.vue (Bagian Submit Schedule)
```typescript
const submitSchedule = async () => {
  if (!scheduleForm.value.route_id) {
    toast({ title: 'Validasi', description: 'Pilih rute terlebih dahulu', variant: 'destructive' })
    return
  }
  if (!scheduleForm.value.vehicle_id || !scheduleForm.value.departure_time || !scheduleForm.value.arrival_time || !scheduleForm.value.price) {
    toast({ title: 'Validasi', description: 'Semua field wajib diisi', variant: 'destructive' })
    return
  }
  submitting.value = true
  try {
    const payload = {
      ...scheduleForm.value,
      travel_date: scheduleForm.value.travel_date || null,
      departure_time: formatTime(scheduleForm.value.departure_time),
      arrival_time: formatTime(scheduleForm.value.arrival_time)
    }
    if (isEdit.value) {
      await api.put(`/schedules/${selectedSchedule.value.id}`, payload)
      toast({ title: 'Berhasil', description: 'Jadwal diperbarui' })
    } else {
      await api.post('/schedules', payload)
      toast({ title: 'Berhasil', description: 'Jadwal ditambahkan' })
    }
    showScheduleDialog.value = false
    isEdit.value = false
    selectedSchedule.value = null
    fetchSchedules()
  } catch (e: any) {
    toast({ title: 'Error', description: e.response?.data?.message || 'Gagal menyimpan', variant: 'destructive' })
  } finally {
    submitting.value = false
  }
}
```

7.4. Script TopupApproval.vue (Bagian Approve Topup)
```typescript
const approveTopup = async (id: number) => {
  const topup = topups.value.find(t => t.id === id)
  const approvingToast = toast({ 
    title: 'Memproses Approval...', 
    description: `Sedang approve top up ${formatCurrency(topup?.amount || 0)}`, 
    duration: 0 
  })
  
  try {
    await api.post(`/topups/${id}/approve`)
    approvingToast.dismiss()
    toast({ title: 'Berhasil', description: `Top up ${formatCurrency(topup?.amount || 0)} berhasil disetujui` })
    showDetailDialog.value = false
    fetchTopups()
  } catch (error) {
    approvingToast.dismiss()
    toast({ title: 'Gagal', description: 'Gagal menyetujui top up', variant: 'destructive' })
  }
}
```
